# 필름 시뮬레이션 LUT 라이선스

이 폴더의 `*.cube` 파일(11종 후지필름 필름 시뮬레이션)은 이 프로젝트(RawLab)
코드와 별개로 다음 라이선스를 따릅니다.

- **출처**: [abpy/FujifilmCameraProfiles](https://github.com/abpy/FujifilmCameraProfiles)
- **라이선스**: CC BY-NC-SA 4.0 (저작자표시-비영리-동일조건변경허락)
  https://creativecommons.org/licenses/by-nc-sa/4.0/
- **조건**: 저작자 표시 필수, **비영리 목적으로만 사용**, 재배포 시 동일 라이선스 적용.
  RawLab 자체(코드)는 이 라이선스의 영향을 받지 않으며, 이 LUT 파일들에만 적용됩니다.
- 이 LUT로 보정한 결과물(사진)에는 라이선스 제약이 적용되지 않습니다(원본 프로젝트
  README 명시 사항).

RawLab을 상업적으로 배포/판매할 계획이 있다면 이 폴더의 LUT는 제외하거나 별도
라이선스를 확인해야 합니다.
